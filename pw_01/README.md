## Описание задачи

**Вариант 24** - Технологические тренды
Бизнес-задача: Инструменты работы с данными: Python-экосистема

Источник API : api.github.com — REST API GitHub (без ключа 60 req/ч, с токеном 5000 req/ч) - использовался токен
Параметры API: {'q': 'pandas dataframe', 'sort': 'stars', 'pages': 2, 'per_page': 50}
Сайт парсинга: webscraper.io/test-sites/e-commerce/allinone (учебный каталог техники)
Параметры    : {'section': 'computers/laptops', 'pages': 3}

Метрики и визуализации:
  Топ-15 по звёздам, динамика последних обновлений, цена ноутбуков vs объём памяти (RegEx)


**Задачи исследования:**
1. Спроектировать вежливый сбор данных через открытый REST API (пагинация, заголовки `User-Agent`, паузы между запросами, повторные попытки `Retry`, кэширование и обработка ошибок).
2. Извлечь данные из статических HTML-страниц двумя независимыми способами — CSS-селекторами (`BeautifulSoup4`) и выражениями `XPath` (`lxml`) — и сверить результаты.
3. Очистить и нормализовать «грязные» текстовые поля (цены, остатки, рейтинги, зарплатные вилки, даты, навыки в тексте требований) с помощью регулярных выражений (`re`).
4. Сформировать итоговые таблицы `pandas.DataFrame`, провести разведочный анализ данных (EDA) и построить визуализации.
5. Сформулировать управленческие выводы и рекомендации на основе рассчитанных показателей.
